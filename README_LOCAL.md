# 🌾 Помощник по ФГИС — Локальный запуск бота

## ⚡ Быстрый старт (3 шага)

### Шаг 1: Установи Python
- Скачай с [python.org](https://python.org) (версия 3.9+)
- При установке поставь галочку **"Add Python to PATH"**

### Шаг 2: Установи библиотеки
Открой терминал (cmd / PowerShell / Terminal) в папке проекта:
```bash
pip install aiogram
```

### Шаг 3: Настрой и запусти

1. Открой `bot_local.py` в блокноте
2. Замени две строчки:
   ```python
   BOT_TOKEN = "ВСТАВЬ_ТОКЕН_СЮДА"
   WEBAPP_URL = "ВСТАВЬ_URL_СЮДА"
   ```

   Например:
   ```python
   BOT_TOKEN = "123456789:ABCdefGHIjklMNOpqrSTUvwxyz"
   WEBAPP_URL = "https://fgis-nu.vercel.app"
   ```

3. Сохрани файл

4. Запусти:
```bash
python bot_local.py
```

5. В Telegram напиши боту `/start`

---

## 🛑 Остановка
Нажми **Ctrl+C** в терминале.

---

## ⚠️ Важно
- Бот работает **только пока терминал открыт**
- Если закроешь терминал — бот выключится
- Для 24/7 нужен сервер (VPS за $3-5/мес)
