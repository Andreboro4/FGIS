# 🌾 Помощник по ФГИС (Telegram Mini App)

Telegram Mini App для аграриев: задачи и сроки по ЕФГИС ЗСН, ФГИС «Зерно», «Семеноводство» и «Сатурн», маршрутный лист, AI-консультант, документы.

---

## ⚡ САМЫЙ ПРОСТОЙ СПОСОБ (без сервера, бесплатно)

### 1. Фронтенд → Netlify (бесплатно, HTTPS)

1. Зайди на [netlify.com](https://netlify.com) → регистрация через GitHub
2. Перетащи папку с `index.html` и `app.js` в окно браузера
3. Получишь URL: `https://fgis-helper-abc123.netlify.app`
4. **Сохрани этот URL** — он понадобится для бота

### 2. Бот → Vercel (бесплатно, не засыпает)

1. Создай репозиторий на GitHub, залей туда:
   - `api/webhook.py`
   - `vercel.json`
   - `requirements.txt`

2. Зайди на [vercel.com](https://vercel.com) → импортируй репозиторий

3. В настройках проекта (Settings → Environment Variables) добавь:
   | Переменная | Значение |
   |------------|----------|
   | `BOT_TOKEN` | твой токен от @BotFather |
   | `WEBAPP_URL` | URL из Netlify (шаг 1) |

4. Нажми **Deploy**

5. Получишь URL бота: `https://fgis-helper-bot.vercel.app/api/webhook`

6. В браузере открой:
   ```
   https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/setWebhook?url=https://fgis-helper-bot.vercel.app/api/webhook
   ```
   (замени `<ТВОЙ_ТОКЕН>` на реальный токен)

7. **Готово!** Бот работает 24/7, не засыпает, бесплатно.

## 🔐 Авторизация

- В Telegram — автовход по `initDataUnsafe.user`
- Гостевой режим — без входа, данные в localStorage
- Организации — сохраняются в браузере

## 📦 Альтернативы хостинга

| Сервис | Для чего | Почему |
|--------|----------|--------|
| **Netlify** | Фронтенд | Drag & drop, HTTPS |
| **Vercel** | Бот (webhook) | Serverless, не засыпает |
| **Cloudflare Pages** | Фронтенд | Быстрый CDN |
| **GitHub Pages** | Фронтенд | Просто, если репо публичный |
| **Render** | Бот (polling) | Бесплатно, но засыпает |
